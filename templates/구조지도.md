# 구조 지도 - (목표 저널)

**언제 만드나**: 통독을 마치고 **목차를 짜기 전에.** 검수 때 만들면 늦다.
**요약하지 않는다.** 절 제목을 낱말 그대로 옮긴다.

---

## 1. 게재작 목차 (그대로 옮겨 적기)

### #N. 저자 (연도) - 저널 권, 논문번호 [총 __쪽]

```
1. Introduction                                    (__쪽, __문단)
2. Theoretical background                          (__쪽)
   2.1 ...                                         (__문단)
   2.2 ...                                         (__문단)
3. Data and methods                                (__쪽)
   3.1 ...
4. Results                                         (__쪽)
   4.1 ...
5. Discussion                                      (__쪽)
6. Conclusion                                      (__쪽)
Appendix A. ...
```

- 가장 긴 절:
- 하위절 깊이: __층까지
- 그림 __개 / 표 __개, 어느 절에:
- 부록 구성:

(논문마다 위 블록을 하나씩 반복한다. 최소 A급 2-4편 + B급 몇 편)

---

## 2. 나란히 놓기

| 자리 | #A | #B | #C | 공통인가 |
|--|--|--|--|--|
| 1절 | Introduction | Introduction | Introduction | 공통 |
| 2절 | Theoretical background | Literature review | Related work | 이름만 다름 |
| 3절 | Data and methods | Methodology | Data / Methods(분리) | **갈림** |
| 4절 | Results | Findings | Results | |
| 5절 | Discussion | Discussion and conclusion | Discussion | **갈림** |
| 6절 | Conclusion | (없음) | Conclusion | |

**공통인 것**(따른다):

**갈리는 것**(우리가 정해야 하는 것):

| 갈리는 자리 | 다수파 | 소수파 | 우리 선택 | 왜 |
|--|--|--|--|--|
| 논의와 결론을 합치나 | | | | |
| 자료와 방법을 한 절로 두나 | | | | |

---

## 3. 절 제목은 실제로 쓰인 것에서 고른다

**창작하지 않는다.** 몇 편이 그 제목을 쓰는지 세어서 고른다.

| 우리 절 | 후보 제목 | 몇 편이 쓰나 | 채택 |
|--|--|--|--|
| 3절 | Data and methods / Methodology / Data collection | | |

- 전체 분량 대역: __-__쪽, 우리 목표 __쪽

## 6. 나중에 다시 볼 것

- [ ] 집필: 각 절을 쓰기 전에 대응하는 게재작 절을 다시 읽었다
- [ ] 검수: 소절·장 층 대조에서 이 지도를 썼다
- [ ] 탈고: 서론의 구성 예고와 실제 절이 맞는지 대조했다
- [ ] 목차가 중간에 바뀌면 **이 파일을 같이 고쳤다**
