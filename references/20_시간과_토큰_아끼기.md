# 같은 검사를 더 싸게 하기

> **이 문서는 "검사를 덜 하라"는 문서가 아니다.**
> 정확도가 먼저다. 여기서 줄이는 것은 세 가지뿐이다.
> ① 대화창에 쏟아 내는 출력 ② 같은 것을 다시 읽는 일 ③ 기계가 이미 확정한
> 판정을 사람이 다시 하는 일. **검사 대상과 판정 대상은 한 줄도 줄이지 않는다.**

---

## 1항. 비용이 어디서 나오는가

| 새는 자리 | 무슨 일이 벌어지나 | 정확도와 관계 |
|--|--|--|
| 대장 전체를 대화창에 찍는다 | 낱말 2,193행 + 문장 779행 + 문단 203행 = 3,175행이 한 번에 들어온다 | **없다.** 판정은 파일을 보고 한다 |
| 도구 출력을 그대로 붙인다 | 같은 표가 검사할 때마다 다시 들어온다 | 없다 |
| 파일을 통째로 읽는다 | 한 줄 고치려고 원고 전체를 연다 | 없다 |
| 회차마다 원고 전체를 다시 읽는다 | 안 고친 절까지 매번 다시 읽는다 | 각도에 따라 다르다(3항) |
| 한 번 잰 것을 또 잰다 | 게재작 대역·인용 분포를 회차마다 다시 계산한다 | 없다 |
| 왕복이 잦다 | 도구 하나 돌리고 결과 보고, 또 하나 돌리고 보고 | 없다 |

**위 여섯 중 다섯은 정확도와 아무 관계가 없다.** 여기부터 줄인다.

---

## 2항. 줄여도 되는 것 일곱

### ① 대장은 파일로, 대화에는 개수와 결론만

```
python word_census.py 원고.md --txt ... --out outputs/낱말대조표.md
python unit_census.py 원고.md --sents --out outputs/문장대장.md
```

`--out` 없이 돌리면 화면에는 위험한 순으로 40행(문장·문단은 30행)만 나오고
전체는 파일로 받으라는 안내가 붙는다. 더 보고 싶으면 `--top 120`.

대화창에는 이렇게만 남긴다.

```
낱말 층: 대상 2,193개 중 코퍼스 0% 263개, 8% 미만 618개.
판정 끝 1,204 / 남음 989. 지금 걸린 것 중 저자가 정할 것: 3건 (아래)
```

**판정 자체는 파일을 열어 전부 한다.** 표본으로 바꾸는 것이 아니다.

### ② 필요한 줄만 연다

`grep -n`으로 자리를 먼저 찾고 그 앞뒤만 읽는다. 원고 전체를 여는 것은
흐름·독자 각도로 읽을 때뿐이다.

**예외: 인용 검증은 원문 문단을 통째로 읽는다.** 앞뒤를 안 보면 지지인지
비판인지 뒤집힌다. 여기서 아끼면 안 된다.

### ③ 기계가 확정한 판정은 사람이 다시 하지 않는다

| 기계가 끝낼 수 있는 것 | 사람이 반드시 봐야 하는 것 |
|--|--|
| 소수점 자리 불일치 | 그 수치가 맞는 수치인가 |
| 참조 번호 미해결 | 그 자리에 그 표를 부르는 게 맞는가 |
| 약어 정의 유무 | 그 약어를 아예 쓰지 말아야 하는가 |
| 5-gram 겹침 위치 | 귀속 인용인가 재구성이 필요한가 |
| 코퍼스 등장 편수 | 뜻·대상·문법 자리·강도·정의가 같은가 |

**오른쪽 칸은 한 건도 건너뛰지 않는다.** 왼쪽 칸만 기계 결과를 그대로 쓴다.

### ④ 한 번 잰 것은 다시 재지 않는다

게재작 대역, 인용 출처 분포, 구조 지도, 텍스트 캐시는 **원고를 고쳐도
안 바뀐다.** 파일로 저장하고 다음 회차에는 읽기만 한다.

바뀌는 것은 원고 쪽 수치뿐이다.

### ⑤ 회차는 고친 자리만 돈다

수정한 절이 3개면 다음 회차 범위는 그 3개다. 회차 대장 범위 칸에 적는다.

**단, 아래 각도는 언제나 전체를 읽는다.** 부분만 읽으면 못 잡는 것들이다.

- 흐름 (문단 사이가 튀는지)
- 독자 관점 (처음 읽는 사람)
- 구성 예고와 실제 절 대조
- 표-본문-초록 삼중 수치 정합

### ⑥ 각도 순서를 수확률 순으로

각도를 **버리는 것이 아니라 순서만 바꾼다.** 지난 논문에서 지적이 많이
나온 각도부터 돈다(`19_각도별_읽기검사.md` 7항의 각도별 건수). 일찍 나온
지적을 고치면 뒤 회차에서 볼 것이 줄어든다.

한 바퀴는 반드시 다 돈다. 순서만 바꾸는 것이다.

### ⑦ 도구는 몰아서 한 번에 돌린다

검사 여러 개를 한 명령으로 이어 돌리고 결과를 한 번에 본다. 하나 돌리고
보고, 또 하나 돌리고 보는 왕복이 가장 비싸다.

## 3항. 절대 줄이면 안 되는 것

**여기서 아낀 것이 전부 사고로 돌아왔다.**

| 줄이면 안 되는 것 | 줄였을 때 실제로 벌어진 일 〔사례〕 |
|--|--|
| 전수 판정 대상 행 수 | "몇 개를 확인했다"로 넘어간 층에서 코퍼스에 없는 낱말이 남았다 |
| 인용 원문 열기 | 105회를 읽고도 인용 방향이 뒤집힌 문장을 못 잡았다. 아무도 원문을 안 열었다 |
| 게재작 직렬 통독 | 여러 편을 한 번에 맡겼더니 있지도 않은 인용을 만들어 냈다 |
| 그림을 이미지로 보기 | 글자만 검사해서 그림 안의 절 번호 오류를 10회차까지 못 봤다 |
| 각도 다양성 | 횟수는 105회인데 각도가 좁아 한 종류를 통째로 놓쳤다 |
| 검사기 자가 시험 | 정규식에 보이지 않는 문자가 섞여 78건이 그대로 통과했다 |

**"시간이 없어서 표본으로 했다"는 기록에 남긴다.** 안 한 것을 한 것처럼
보고하지 않는다.

## 4항. 대화 답변에 담을 것과 안 담을 것

| 담는다 | 안 담는다 |
|--|--|
| 진행률 줄 | 대장 전체 |
| 이번 층·이번 각도의 개수 | 도구 출력 원문 |
| 판정이 갈린 것 상위 몇 건 | 이미 말한 규칙 다시 인용 |
| **저자가 정해야 할 것** | 다음에 할 일 목록 반복 |
| 어느 파일에 무엇이 저장됐는지 | 방금 한 일 되풀이 설명 |

---

## 5항. 얼마나 줄어드나 〔사례〕

| 항목 | 전 | 후 | 판정 품질 |
|--|--|--|--|
| 대장 3종 화면 출력 | 3,175행 | 100행 + 파일 3개 | 같다 (같은 파일로 판정) |
| 대역 재계산 | 회차마다 | 한 번 | 같다 |
| 파일 열기 | 원고 전체 | grep한 줄 앞뒤 | 같다 |

**판정 품질이 "같다"인 것만 줄인다.** "조금 떨어진다"는 줄이지 않는다.

---

## 6항. 잘못된 절약 (하지 말 것)

- 통독을 병렬 에이전트로 나눠 맡기기
- "대표 몇 개만 확인했습니다"로 층을 닫기
- 원문 대신 요약본으로 인용 검증하기
- 검사기를 안 돌리고 눈으로만 보기
- 회차 수를 줄이면서 각도까지 줄이기
- 표·그림을 글자로만 보고 이미지로 안 보기

이 여섯은 **비용이 아니라 정확도를 깎는다.** 다음 회차에서 더 비싸게 돌아온다.
