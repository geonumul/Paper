# 국문 문체

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차와 규칙은 분야·저널과 무관하게 쓰지만, 숫자와 사례는 **특허·건설 분야
> 논문 한 편(목표 저널 TFSC)에서 실제로 잰 값**입니다. 〔사례〕 표시가 붙은
> 것은 전부 그 논문 이야기입니다. **자기 저널에서 같은 방식으로 다시 재서
> 바꿔 넣으세요.** 무엇을 재는지가 이 문서의 내용이고, 얼마가 나오는지는
> 저널마다 다릅니다.


**영문은 목표 저널 실측, 국문은 사용자 본인 원고 실측.** 국문 문체의 정본은
사용자가 이미 쓴 학술 원고다. 없으면 같은 분야 국문 학술지 논문을 정본으로
삼는다.

국문이 중요한 이유가 따로 있다. **지도교수나 공저자가 영어를 직접 검수하지
못하면 국문 대역이 유일한 검수 통로다.** 국문이 어색하면 검수 자체가 되지
않는다.

---

## 1. 먼저 정본을 실측한다

사용자 원고(예: 31쪽짜리 국문 학술 원고)를 통독하면서 다음을 뽑는다.

- 기둥 구문(가장 자주 나오는 문장 골격)
- 종결어미의 기능별 분포
- 문장 길이와 쉼표 사용
- 표·그림 참조 형식
- 장 도입 문단의 형식
- 인용 표기(두 저자, 셋 이상)
- 지시·연결어 목록

이 실측이 없으면 "자연스러운 한국어"라는 감으로 쓰게 되고, 그러면 에세이투가
된다.

## 1-2. 국문도 기계로 잰다

영문 도구(`check_ngram.py`)는 국문 문장을 못 센다. 국문 전용으로 잰다.

```bash
python scripts/ko_measure.py 원고_국문.md --ref <정본원고.txt>
python scripts/word_census.py 원고_국문.md --ko --txt <국문코퍼스폴더>
python scripts/unit_census.py 원고_국문.md --paras   # 절·문단·문장 대장
```

`ko_measure.py`가 재는 것: 문장 길이(어절)·변동계수, 문단당 문장 수,
**종결어미 분포**(사실 보고/해석/함의/제안/의의), 기둥 구문 빈도, 걷어낼 버릇
(도치·구어·모호한 기간·번역투). 정본과 나란히 놓고 다른 항목을 표로 낸다.

**띄어쓰기가 깨진 텍스트는 못 잰다.** 국문 PDF에서 뽑은 텍스트는 어절이 붙어
나와서 문장 길이가 엉터리로 계산된다. 도구가 이를 감지하면 수치를 내지 않고
"잴 수 없다"고 말한다. 그때는 **띄어쓰기가 살아 있는 원본**(원고 파일, 한글
문서에서 복사한 텍스트)으로 다시 재거나, **"재지 못했다"고 기록**한다.

같은 이유로 `word_census --ko`도 코퍼스가 깨져 있으면 거의 전부 "없음"으로
나온다. 대조 대상의 절반 넘게 없음으로 나오면 **우리 낱말이 아니라 코퍼스가
문제다.** 도구가 경고를 낸다.

실제 측정 예(우리 국문 원고): 문장 386개, 평균 20.3어절, **길이 편차/평균 0.70**, 문단당
중앙값 4문장, 종결어미는 사실 보고 94%.

## 2. 실측된 골격 (사례)

- **기둥 구문은 "~한 결과, ~하였다"**: "독립표본 t-검정으로 검토한 결과,
  6개 중 4개에서 유의하였다"
- **종결은 기능별로 배분한다**

| 기능 | 종결 |
|--|--|
| 사실 보고 | -하였다 / -나타났다 / -확인되었다 |
| 해석 | -로 해석된다 / -해석할 수 있다 |
| 함의 | -를 시사한다 / -를 보여 준다 |
| 제안 | -할 필요가 있다 |
| 의의 | -라는 점에서 의의를 지닌다 |

- **긴 명사구 주어 + 쉼표 흐름.** 짧은 단문을 끊어 연타하지 않는다
- **대조 연결**: "~하였으나, ~" / "반면 ~" / "다만 ~" / "한편 ~"
- **표 참조는 별도 문장**: "검정 결과는 표 7에 제시하였다."
- **장 도입 예고 문단**: "본 장에서는 ~를 살펴본다. 우선 ~. 이어 ~. 이를 통해
  ~로 본 장을 마무리한다."
- **번호 문단**: 결론·시사점은 "첫째, ~. 둘째, ~. 셋째, ~"
- **개념 병기**: 첫 등장에 한글(English). "기준점(Baseline)"
- **인용 표기**: 두 저자는 "Gann과 Salter(2000)", 셋 이상은 "Hale et al.(2013)"
- **지시·연결어**: "이러한", "해당", "본 연구는", "이를 통해", "이를 바탕으로",
  "나아가", "특히", "그 결과"

## 3. 에세이투를 걷어내는 변환표

실제로 전량 재작성하며 쓴 표다.

| 버릇 | 학술 문체로 |
|--|--|
| 은유·의인: "펼쳐 놓는다", "손을 잇는다", "자국을 남긴다", "그림이 맞으려면", "결이 있다", "얇게 남는다", "먹인다", "물음을 연다" | 표준 학술 동사: "제시한다", "이어진다", "관찰되었다", "해석과 일치한다", "적었다" |
| 도치·강조: "볼 곳은 공급 측이다", "변한 것은 ~이다" 남발 | 표준 어순, 필요하면 "~는 ~에 있다" |
| 짧은 단문 연타: "둘째는 침묵이다." | 쉼표로 잇는 흐름 문장 |
| "-다"의 단조 반복 | 기능별 종결 배분(2항) |
| 구어 어휘: "답", "무늬", "판", "몫이 크다", "세게" | "대안", "양상", "설정", "비중이 크다", "강하게" |
| 모호한 기간: "최근 10년 사이", "십여 년간" | 연도 명시: "2013년 이후", "2013-2022년" |

## 4. 금지 문구

- **"십여 년간", "십수 년간"** - 연도를 명시한다
- **"널리 도입된", "널리 활용되고"** - 구체 서술로
- **"~인지 규명하기 위해" 틀** - "~를 검토한다 / 분석한다 / 확인한다"로
  (다만 "규명하려는 실증 연구"처럼 쓰는 것은 실측 용례가 있다)
- **번역투**: "~에 의해 특징지어진다" 류의 구조
- 물결표, em dash, 은어, 조어 금지는 그대로

## 5. 이중 출력 규칙

- 문단마다 **영문(저널 스타일)과 국문(학술 문체)을 둘 다** 낸다
- **영문이 정본, 국문은 검토용 대역**이다
- **한쪽만 고치면 반드시 표류한다.** 영문을 고치면 국문도 같은 자리에서 고치고,
  문단쌍을 나란히 놓고 대조하는 회차를 따로 둔다
- 국문 대역에서 **표는 본문에 넣고 그림은 `[그림 1. 제목]` 위치 표시만** 남긴다
- 수치와 문단 의미는 영문과 완전히 같아야 한다. 문체만 다르다

## 6. 국문 검수 항목

`check_style.py`가 국문 금지어(십여 년간·널리 도입된·~는지 규명하기 위해)를
잡는다. 나머지는 눈으로 본다.

```
□ 기둥 구문이 "~한 결과, ~하였다" 형태로 들어가 있는가
□ 종결어미가 기능별로 배분되었는가 ("-다" 단조 반복이 아닌가)
□ 은유·의인·도치가 남아 있지 않은가
□ 구어 어휘가 남아 있지 않은가
□ 기간이 연도로 명시되었는가
□ 개념 병기가 첫 등장에만 있는가
□ 인용 표기가 "A와 B(2000)" / "A et al.(2013)" 형식인가
□ 영문 대역과 수치·의미가 일치하는가
```
