# 영작 규칙

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차와 규칙은 분야·저널과 무관하게 쓰지만, 숫자와 사례는 **특허·건설 분야
> 논문 한 편(목표 저널 TFSC)에서 실제로 잰 값**입니다. 〔사례〕 표시가 붙은
> 것은 전부 그 논문 이야기입니다. **자기 저널에서 같은 방식으로 다시 재서
> 바꿔 넣으세요.** 무엇을 재는지가 이 문서의 내용이고, 얼마가 나오는지는
> 저널마다 다릅니다.


**우선순위**: ①전역·프로젝트 규칙 → ②목표 저널 게재작 관행 → ③일반 영작
가이드. 충돌하면 위가 이긴다.

| 충돌 | 판정 |
|--|--|
| 가이드는 "to the best of our knowledge, the first…"를 허용 | **우리 규칙 우선: '처음' 주장 자체를 안 쓴다** |
| 가이드의 m-dash 사용법 | **전역 규칙 우선: em dash(—) 전면 금지.** 부연은 쉼표나 괄호로 |
| 가이드는 "~5 nm" 같은 물결표 근사를 허용 | **전역 규칙 우선: 물결표 금지.** approximately로 풀어 쓴다 |
| 가이드는 however를 엄격히 제한 | **조화**: 진짜 반전에만 However, 단순 대비는 In contrast/whereas. 다만 저널의 이음말 밀도 대역(쪽당 2-3회)은 유지 |

## 1. 우리 원고에서 특히 자주 걸리는 것

| 항목 | 규칙 |
|--|--|
| **that vs , which** | 제한이면 that(쉼표 없음), 부가 설명이면 ", which". **유일한 값(수치·지표명) 뒤는 반드시 ", which"**: "AUC of 0.842, which was maintained out of sample" |
| **however 콤마 접속 금지** | "문장1, however, 문장2" 금지. 마침표나 세미콜론으로 |
| **자동사 수동태 금지** | is occurred / is resulted / is appeared / is succeeded. **result는 "This results in…"** |
| **지시대명사 명시** | It indicates → **This result indicates**. this 단독 금지 |
| **명사 3연속 금지** | "patent classification co-occurrence network prediction"은 of/for로 푼다 |
| **significant는 검정했을 때만** | p값이 붙는 자리에서만. 그 외에는 substantial·considerable·marked |
| **prove 금지, 이중 완화 금지** | "may possibly suggest" 금지. 강도 사다리: suggest < indicate < show < demonstrate |
| **인과 동사 금지(관찰 자료)** | "increased the yield" 대신 "increased with", "is consistent with", "is attributed to" |
| **respectively 개수 일치** | 앞 목록과 뒤 서술 개수를 센다. 넷 이상이면 표로 |
| **비교 대상 명시** | "higher than **that of** the baseline". that of 생략 금지 |
| **문두 아라비아 숫자 금지** | "A total of 4,200 applications…"로 회피 |
| **소수점 앞 0** | 0.842 (.842 금지). 곱셈은 ×, 범위는 하이픈(5-10) |
| **단위·숫자** | 문장 안 10 미만은 단어(three industries), 단위가 붙으면 숫자 |
| **축약형 금지** | don't, it's |
| **i.e./e.g.** | 뒤에 콤마. e.g.와 etc. 병용 금지. **et al.**은 et 뒤 마침표 없음, 복수 취급 |
| **each/per 뒤 단수** | each 남용 금지. 수가 정해져 있으면 two/both |
| **amount/number, less/fewer** | 셀 수 있는 것에는 number, fewer |
| **due to는 서술 자리만** | 문두 부사구는 owing to / because of |
| **This paper investigates 지양** | "In this paper, we investigate". 단 "This study shows"는 허용 |
| **Methods는 수동·과거 허용**, 나머지는 we 능동 기본 | 저널 관행과 일치 |
| **오차 표기** | 자리수 맞춤(5.32 ± 0.04), 단위는 뒤에 한 번 |

## 2. 전치사·어휘 세트 (실제로 자주 틀린 것)

- **Similar to** (○) / similar with·as (✗)
- **Related to** (○) / related with (✗)
- **Replace A with B** (○) / replace A to B (✗)
- **in Figure 2** (○) / on Figure 2 (✗)
- **before vs until**: until은 그 시점을 기준으로 상황이 달라질 때. 논문에서는
  until이 더 잦다
- **following vs subsequent**: following은 현재 시점 이후, subsequent는 앞에
  언급된 시점 뒤. "the mixing and the **subsequent** purification"
- **below는 형용사가 아니다**: the below table (✗) → the following table /
  the table below / 가장 좋은 것은 **Table 3**처럼 번호로
- **by contrast vs in contrast**: `in contrast to + 명사`는 되지만
  `by contrast to + 명사`는 안 된다. 두 문장 대비는 둘 다 가능
- **otherwise**는 경우가 셋 이상일 때. 둘뿐이면 "in the other case"로 푼다

**전체와 부분을 나타내는 동사**

| 동사 | 어순 | 수동태 |
|--|--|--|
| comprise | 전체 + comprise + 모든 구성요소 | `is comprised of` ✗ |
| compose | 구성요소 + compose + 전체 | `is composed of` ○ |
| consist of | 전체 + consist of + 모든 구성요소 | `is consisted of` ✗ |
| constitute | 구성요소 + constitute + 전체 | - |
| contain / include | 전체 + contain + 일부 | - |

## 3. 시제 3층

- 선행연구 정리: **현재완료** ("Prior work has treated …")
- 우리 절차: **과거** ("we constructed", "we scored")
- 정의·표 설명·결과 진술: **현재** ("Table 3 reports", "The results indicate")

**"할 것이다" 시제로 방법을 쓰지 않는다.** "is evaluated"라고 써 놓고 값이 없는
것은 안 한 것이라는 신호다.

## 4. 절별 전형 문구

그대로 복사하지 않고 내용에 맞게 바꾼다. 다만 **저널 게재작에서 실제로 채집한
문형이 있으면 그쪽을 먼저 쓴다.**

**초록**(4-6문장): 배경 → 공백 → 본 연구 → 핵심 수치 → 의의.
인용·그림 참조·미정의 약어 금지. **약어는 초록과 본문에서 각 1회씩 정의한다.**

**서론**: 공백은 "Despite these efforts, … remains poorly understood" 형식.
마지막 문단에서 본 연구를 선언한다.

**결과**: 그림 지시 "Figure 2 shows / As shown in Figure 2". 관찰 "We observed".
해석 연결 "This result indicates that". 대비 "In contrast, …".

**논의**: 종합 "Taken together, these results suggest that". 선행연구 비교
"This finding is consistent with". 대안 해석 "An alternative explanation is that"
/ "We cannot completely rule out the possibility that".

**한계**: "One limitation of this study is that" / "The present analysis is
restricted to" / "Further studies are needed to clarify".

**결론**: "In summary" / "In conclusion". **초록을 그대로 복사하지 않는다.**

## 5. 제목·키워드

- 제목: 문두 관사 생략, 자체 약어 금지, 명사 나열 금지
- 키워드: 제목에 없는 검색 보완어로 3-6개. `and`/`of`가 들어간 구는 피한다

## 6. 도구 사용 절차

영문화한 뒤 순서대로 한다.

1. `check_style.py`(기계 8종)와 `check_ngram.py`(5-gram + 리듬)
2. 문법 검사 도구를 **한 번만**, "필요한 경우에만 제안하라"는 지시로 돌린다
   (변형을 최소화하는 지시어를 쓴다)
3. 헷갈리는 표현은 **따옴표를 씌워 검색**해 실용례를 확인한다
4. **도구 제안을 무비판적으로 받지 않는다.** 복수형 오판, 의미를 바꾸는 제안
   사례가 실제로 있었다

## 7. 심사 답변서

- 코멘트를 **전부 번호로** 나눈다
- 각 답변에 **수정된 실제 문장 + 위치(page, lines)**를 적는다
- 반박은 근거와 함께: "We respectfully disagree… because"
- 수행 불가는: "beyond the scope… Instead, we have provided…"
- **답변의 근거 창고는 검증 기록이다.** 부정 결과와 강건성 검사를 미리 계산해
  두었으면 여기서 꺼내 쓴다. 본문에 안 실은 것도 답변서에는 쓸 수 있다
