# 전체 흐름과 한 장 체크리스트

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차와 규칙은 분야·저널과 무관하게 쓰지만, 숫자와 사례는 특허·건설 분야
> 논문 한 편(목표 저널 TFSC)에서 실제로 잰 값입니다. 〔사례〕 표시가 붙은
> 것은 그 논문 이야기입니다.

**이 스킬은 원고를 써 주지 않는다.** 이미 쓴 원고를 목표 저널 게재작과
대조해 고칠 곳을 찾아 주는 것이 전부다.

## 1. 단계마다 무엇이 나오는가

| 단계 | 하는 일 | 산출물 | 다음 단계에서 쓰임 |
|--|--|--|--|
| 0 확인 | 원고 파일, 보유 논문 폴더, 목표 저널 | 시작 기록 | 전 단계 |
| 1 저널 | SCI·SCIE 확인, 제외 대상 거르기, 후보 좁히기 | 저널 결정과 근거 | 모든 기준의 출처 |
| 2 수집 | 폴더 진단, 부족분 목록 제시, 받은 뒤 재진단 | 게재작 40편 이상 | 대역·기준 |
| 3 실측 | 문장 길이·리듬·이음말·한계 분량·참고문헌 수 | 대역표(숫자) | 검수 통과 기준 |
| 4 인용 분포 | 그 저널이 어느 저널을 몇 % 인용하는가 | 분포표 | 추가 수집 목록, 우리 인용과 대조 |
| 5 기준 뽑기 | 게재작을 한 편씩 읽고 관찰을 규칙으로 | 검수 기준, 구조 지도 | 검수 판정의 근거 |
| 6 기계 검사 | 문체·리듬·규격·참조·수치 정합 | 검사 보고서 | 통과 전 다음 층 금지 |
| 7 전수 대조 | 낱말 → 문장 → 문단 → 소절 → 장 → 전체 | 대조 대장 | 수정 목록 |
| 7-2 각도별 읽기 | 흐름·맥락·방법·결과·문법·내용·독자 관점으로 읽는다 | 회차 대장 | 수정 목록 |
| 8 인용 검증 | 원문을 열어 다섯 항목 확인 | 인용 대장 | 수정 목록 |
| 9 번역 대조 | 두 판이 같은 말을 하는가 | 번역 대장 | 수정 목록 |
| 10 그림·표 | 양식을 수치로 재고 이미지로 대조 | 사양서 | 그림 수정 |
| 11 AI 티·위생 | 리듬·기호·보이지 않는 문자·익명성 | 정리된 파일 | 제출 |
| 12 투고 점검 | 규격·조판·서약·파일 목록 | 제출 폴더 | 투고 |

**3단계를 건너뛰면 나머지가 전부 근거 없는 지적이 된다.** 대역이 없으면
"이게 자연스럽다"로 돌아간다.

## 2. 순서를 지켜야 하는 이유

- **기계 검사를 먼저 돌린다.** 여기서 나오는 것이 가장 싸게 고쳐진다
- **한 번에 한 층위만 들고 문서 처음부터 끝까지 간다.** 장별로 깊게 파면 그
  층위의 패턴이 안 보인다
- **인용 검증은 따로 돈다.** 다른 어떤 검사로도 안 걸리기 때문이다
- **번역 대조는 두 판이 다 있을 때만.** 한쪽을 고치면 다시 돌린다

## 3. 한 장 체크리스트

```
[준비]
□ 검수할 원고 파일을 확인했다 (영문·국문 어느 쪽이 기준인지도)
□ 보유 논문을 세었다 (전체 몇 편, 목표 저널 몇 편)
□ 목표 저널이 SCI·SCIE인지, 제외 대상이 아닌지 확인했다
□ 폴더를 진단했다 (편수·못 쓰는 파일·연도·중복·인용 공백)
□ 게재작 40편 이상을 확보했다 (모자라면 목록을 만들어 요청했다)
□ 대역이 더 안 흔들리는지 확인했다 (--stability)
□ 텍스트 캐시를 만들었다
□ 대역을 실측했다 (문장 길이, 리듬, 이음말, 한계 분량, 참고문헌 수)
□ 그 저널의 인용 출처 분포를 냈다

[기준 뽑기]
□ 게재작을 한 편씩 직렬로 읽었다 (배치 병렬 금지)
□ 편마다 같은 칸을 채웠다 (글쓰기 관찰 + 따라 하지 말 것)
□ 구조를 절·문단·문장 단위까지 뜯어 지도를 만들었다
□ 규칙마다 근거 논문 번호를 달았다

[기계 검사]
□ 문체 검사 통과
□ 규격·참조·수치 정합 검사 통과
□ 5-gram 겹침 0건 (걸린 것은 귀속 인용이거나 완전 재구성)
□ 변동계수가 실측 대역 안
□ 보이지 않는 문자와 티 나는 기호 정리

[전수 대조]  (방법은 15번, 기록은 대조검수_대장)
□ 진행 상태를 파일로 두고 한 턴에 한 단계만 했다 (progress.py)
□ 행마다 **판정과 근거를 둘 다** 채웠다 (근거는 게재작의 어느 자리인지까지)
□ 낱말  전수 대조표를 만들고 모든 행에 판정을 적었다 (판정 안 한 행 0)
□ 낱말  8% 이상인 것도 맥락 다섯(뜻·대상·문법 자리·강도·정의)을 확인했다
□ 문장  대장을 만들고 모든 행에 판정을 적었다
□ 문단  모든 문단에 카드가 있다 (카드 없는 문단 0)
□ 문단  메시지만 모아 서론부터 결론까지 이어 읽었다
□ 소절  목적이 한 줄로 써지는가 / 게재작 같은 소절과 대조
□ 장    서두 예고와 소절 일치 / 나열인가 연쇄인가 / 경계 전환
□ 전체  후렴 / 구성 예고 / 삼중 수치 정합 / 용어 일관
□ 층위마다 새 지적이 연속 두 번 0건일 때 닫았다

[각도별 읽기]  (방법은 19번)
□ 각도를 하나씩 들고 처음부터 끝까지 읽었다 (한 번에 한 각도만)
□ 회차마다 각도·범위·새 지적 수를 대장에 적었다
□ 독자 관점을 봤다 (처음 읽는 사람 / 표만 / 그림만 / 초록만 / 결론만)
□ 종료 조건을 정하고 그대로 멈췄다 (횟수 제한 또는 연속 0건)
□ 렌즈를 늘리는 대신 층위를 올렸다

[인용]
□ 본문 인용을 전수로 뽑고 개수를 보고했다
□ 참고문헌과 양방향으로 대조했다 (미인용 항목 정리)
□ 참고문헌 제목을 읽고 방향을 확인했다
□ 원문을 열어 다섯을 확인했다 (그 말을 하는가 / 지지인가 비판인가 /
  그 수치가 있는가 / 조건이 같은가 / 글자가 맞는가)

[번역]  (두 판이 있을 때)
□ 어느 쪽이 기준인지 정했다
□ 단위 수·수치·인용·약어를 대조했다
□ 문단쌍 전수로 다섯을 봤다 (같은 말 / 수치 / 수위 / 조건 / 용어)

[그림·표]
□ 게재작 양식을 수치로 뽑고 이미지로도 봤다
□ 사양서의 모든 항목을 채웠다 ("모르겠다"가 없다)
□ 우리 것과 나란히 놓고 다른 점 목록이 빌 때까지 고쳤다
□ 그림 안의 글자(절 번호·모수·계열 이름)를 본문과 대조했다
□ 표의 셈을 검산했다

[제출]
□ 초록 낱말 수, 하이라이트 개수·글자 수, 키워드 개수가 규정 안
□ 조판 오류 0건, 미해결 참조 0건
□ 인쇄된 PDF에서 글자를 뽑아 최근 수정이 들어갔는지 확인
□ 익명성 확인 (본문·각주·파일 속성·저장소 주소)
□ 서약·저자 기여 문구 준비
□ 건너뛴 단계를 기록에 남겼다
```

## 4. 이 절차의 실제 규모 〔사례〕

논문 한 편을 이 방식으로 마무리했을 때의 분량이다.

- 게재작 등 문헌 152편 통독, 기록 25,806줄
- 글쓰기 관찰 154개
- 문제 기록 70여 건
- 검수 회전 10회차 + 층위 6단계
- 목표 저널 게재작 59편의 초록만 따로 정독
- 원고 한 편에서 낱말 2,186개, 문단 203개, 문장 779개가 판정 대상
