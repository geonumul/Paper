# 전체 흐름과 한 장 체크리스트

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차와 규칙은 분야·저널과 무관하게 쓰지만, 숫자와 사례는 **특허·건설 분야
> 논문 한 편(목표 저널 TFSC)에서 실제로 잰 값**입니다. 〔사례〕 표시가 붙은
> 것은 전부 그 논문 이야기입니다. **자기 저널에서 같은 방식으로 다시 재서
> 바꿔 넣으세요.** 무엇을 재는지가 이 문서의 내용이고, 얼마가 나오는지는
> 저널마다 다릅니다.


## 1. 단계마다 무엇이 나오는가

| 단계 | 하는 일 | 산출물 | 다음 단계에서 쓰임 |
|--|--|--|--|
| 0 준비 | 문헌을 갈래별 폴더로 나눔, 목표 저널 게재작 20편 이상 확보 | `literature/5_저널게재작/`, 텍스트 캐시 | 모든 기준의 근거 |
| 0-A 실측 | 문장 길이·변동계수·이음말 밀도·한계 분량·참고문헌 수·주석 길이 측정 | 대역표(숫자) | 검수 통과 기준 |
| 1 통독 | 한 편씩 직렬로 읽고 같은 칸을 채움 | 통독 기록(편당 한 항목), 문제 카드 | 규칙서·용어 사전·인용 은행 |
| 2 구조·규칙서 | **게재작 목차를 나란히 놓고 우리 목차를 먼저 정한 뒤**, 글쓰기 관찰에서 규칙을 뽑는다 | 구조 지도, 규칙서 14부 | 집필·검수의 정본 |
| 3 집필 | 규칙을 지키며 씀. 문단마다 승인 기록 | 원고 초고(영문 정본 + 국문 대역) | 검수 대상 |
| 4 기계 | 문체 8종 + 5-gram + 리듬 | 검사 보고서 | 통과 전 다음 층 금지 |
| 5 대조 | 낱말 → 문장 → 문단 → 소절 → 장 → 전체를 게재작과 직접 대조하고, 새 지적이 안 나올 때까지 재독 | 대조검수 대장(근거·판정·수렴 기록), 확정 findings | 수정 실행 |
| 6 재순회 | 각도를 바꿔 아홉 회차 | 추가 findings | 수정 실행 |
| 7 글 밖 | 그림 양식, 판면, 국문 문체 | 그림 파일, 국문 대역 | 제출본 |
| 8 위생 | 보이지 않는 문자, 파일 속성, 익명성 | 정리된 제출 파일 | 제출 |
| 9 제출 | 규격 확인, tex 컴파일, 서약·CRediT | `제출/` 폴더 하나 | 투고 |

**0-A를 건너뛰면 나머지가 전부 근거 없는 판단이 된다.** 대역이 없으면
"이게 자연스럽다"로 돌아간다.

## 2. 순서를 지켜야 하는 이유

- **집필을 먼저 완주하고 검수는 그 뒤에 일괄로 한다.** 문단 하나 쓰고 검수하고
  다시 쓰면 층위가 섞여 같은 종류의 결함을 놓친다
- **한 번에 한 층위만 들고 문서 처음부터 끝까지 간다.** 장별로 깊게 파면 그
  층위의 패턴이 안 보인다. 실제로 세로로 파다가 가로 훑기로 재시작했다
- **초록은 마지막에 쓴다.** 본문 수치가 확정되기 전에 쓰면 삼중 정합이 깨진다

## 3. 한 장 체크리스트

```
[준비]
□ 문헌을 갈래별 폴더로 나눴다. 목표 저널 게재작 폴더를 따로 뒀다 (20편 이상)
□ 게재작에서 대역을 실측했다 (문장 길이, 변동계수, 이음말 밀도, 한계 분량,
  참고문헌 수, 주석 길이, 부록 관행)

[통독]
□ 기록 파일 앞에 목적과 내 주장 목록을 적었다
□ 위험한 것부터 읽는 순서를 정했다
□ 한 편씩 직접, 처음부터 끝까지 읽었다 (배치 병렬 금지)
□ 편마다 같은 칸을 채웠다 (글쓰기 관찰 여섯 항목 + 따라 하지 말 것)
□ 넘긴 자리(수식·부록·사례)를 표시해 뒀다가 2차로 되짚었다
□ 반복되는 병리는 횟수를 셌다
□ 종합 절을 A부터 D로 정리했다

[구조]
□ 게재작 목차를 요약하지 않고 그대로 옮겨 적었다
□ 절 순서를 나란히 놓고 공통인 것과 갈리는 것을 갈랐다
□ 절 제목을 실제로 쓰인 것 중에서 골랐다 (몇 편이 쓰는지 세었다)
□ 절별 분량 대역을 재고 우리 목표를 정했다
□ 우리 목차의 절마다 대응하는 게재작 자리를 적었다
□ 다수파와 다르게 가는 자리는 이유를 적었다

[규칙서]
□ 규칙마다 근거 논문 번호를 달았다
□ AI향 제거 항목(리듬·나열·접속·금지어·배치)을 넣었다
□ "연구 시작 전에 쓸 수 있었는가" 물음을 넣었다

[기계 검사]
□ 문체 검사 8종 통과
□ 5-gram 겹침 0건 (걸린 것은 귀속 인용이거나 완전 재구성)
□ 변동계수가 실측 대역 안

[층위별 직접 대조]  (방법은 15번, 기록은 대조검수_대장)
□ 낱말  걸린 자리 → 코퍼스 빈도 + 쓰인 문장 확인 → 원고 안에서 대체어
□ 문장  기능 판정 → 같은 기능의 게재작 문장을 앞뒤와 함께 읽음 → 여섯 항목 대조
□ 문단  메시지 한 줄 / 빌드업 / 근거 게재작 문단 지목 / 앞 문단과의 연결
□ 문단  메시지만 모아 서론부터 결론까지 이어 읽음 (사슬 검사)
□ 소절  목적 한 줄이 써지는가 / 문단 배열 논리 / 게재작 같은 소절과 대조
□ 장    서두 예고와 소절 일치 / 나열인가 연쇄인가 / 경계 전환
□ 전체  후렴 / 구성 예고 / 삼중 수치 정합 / 용어 일관 / 게재작 통독 후 우리 것 통독
□ 층위마다 새 지적이 연속 두 번 0건일 때 닫았다

[각도 바꿔 재순회]
□ 적대적 심사자 / 인용 정확성 / 어휘 사다리 / AI 티 / 표 자립성 / 선례 검증
□ 소수점 자리 / 약어 최초 정의 / 마무리

[글 밖]
□ 그림을 게재작 실물과 대조해 스타일을 교체 (데이터는 그대로)
□ 그림 정렬 일곱 항목 점검
□ (국문판이면) 문체 변환 규칙표 적용

[최종 위생]
□ 보이지 않는 문자 검사만 먼저 (판정 등급 확인)
□ A층만 정리 (--stats 기록)
□ diff로 원본 대조 (글자가 안 바뀌었는지)
□ 제출 파일 속성 제거 (PDF는 qpdf 필요)
□ 그림 파일 메타데이터 확인 (픽셀은 건드리지 않음)
□ 익명성 눈으로 최종 확인
□ 본문 재작성 도구(B층) 안 돌렸다  ← 이것만은 확인

[제출]
□ 초록 낱말 수, 하이라이트 개수·글자 수, 키워드 개수가 규정 안
□ tex 컴파일 오류 0건, 미해결 참조 0건
□ 인쇄된 PDF에서 글자를 뽑아 고친 내용이 실제로 들어갔는지 확인
□ 제출 폴더 하나로 정리, 낡은 사본 삭제
□ CRediT·데이터 서약·이해충돌·생성형 AI 신고 문구 준비
```

## 4. 이 과정의 실제 규모 (참고용 실적)

한 편을 이 방식으로 마무리했을 때의 분량이다. 다음 논문의 일정을 잡을 때 쓴다.

- 문헌 152편 통독, 기록 25,806줄
- 글쓰기 관찰 블록 154개
- 문제 일지 카드 72개 이상
- 검수 회전 10회차 + 층위 6단계
- 목표 저널 게재작 59편의 초록만 따로 정독(형식 실측)
- 확정 findings F1부터 F15까지, 되돌린 것 1건 포함
