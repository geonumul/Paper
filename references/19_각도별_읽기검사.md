# 각도별 읽기 검사 (그냥 읽으면서 보는 것)

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차는 분야·저널과 무관하지만, 숫자와 사례는 특허·건설 분야 논문 한 편에서
> 나온 것입니다. 〔사례〕 표시가 붙은 것은 그 논문 이야기입니다.

기계 검사와 전수 대장은 **빠진 것을 잡는다.** 그런데 다 통과해도 읽으면
이상한 글이 있다. 그건 **처음부터 끝까지 읽어야만** 보인다.

이 문서는 그 읽기를 어떻게 하는지, 그리고 **몇 번 돌 것인지**를 정한다.

---

## §1. 읽는 방식

- **한 번에 한 각도만 들고 처음부터 끝까지 간다.** 여러 각도를 동시에 보면
  그 각도의 패턴이 안 보인다
- **기계 결과와 대장을 안 보고 읽는다.** 방금 고친 자리를 잊고 읽어야 한다
- **걸린 자리만 적는다.** 개수를 정해 놓고 채우지 않는다
- 걸렸는데 왜 걸렸는지 모르겠으면 **"이유 모름"으로 적고 넘어간다.** 나중에
  같은 자리가 또 걸리면 그때 이유가 보인다
- 한 회차가 끝나면 **새 지적 수를 기록한다.** 이 숫자가 회차 관리의 근거다

## §2. 여섯 측면

### ① 흐름

문장에서 문장으로, 문단에서 문단으로, 절에서 절로 **끊기지 않고 이어지는가.**

| 걸리는 신호 | 예 |
|--|--|
| 앞에서 안 나온 개념이 갑자기 나온다 | 3장에서 정의할 말을 2장에서 씀 |
| 뒤에서 할 말을 앞에서 미리 해 버린다 | 결과를 서론에서 말함 |
| 문단 사이가 튄다 | 앞 문단 끝과 다음 문단 첫 문장이 손을 안 잡음 |
| 같은 말을 두 번 한다 | 4장에서 한 설명을 5장에서 다시 |
| 예고와 실제가 다르다 | "세 가지를 본다"고 하고 둘만 다룸 |

**읽는 법**: 소리 내 읽듯이 이어 읽는다. 멈칫하는 자리가 곧 끊긴 자리다.

### ② 맥락

각 문장이 **그 자리에 있어야 하는가.** 독자가 그 시점에 아는 것만으로 읽히는가.

| 걸리는 신호 | 예 |
|--|--|
| 정의 전에 쓴 용어 | 3.3절에서 정의할 말을 3.1절에서 씀 |
| 독자가 모르는 것을 안다고 전제 | 우리 자료의 특성을 설명 없이 씀 |
| 문장이 그 절의 목적과 무관 | 방법 절에 결과 해석이 섞임 |
| 인용이 그 자리에 필요 없다 | 상식적인 문장에 인용 셋 |

### ③ 방법

**남이 이 글만 보고 다시 할 수 있는가.**

| 걸리는 신호 | 예 |
|--|--|
| 단계가 빠졌다 | 전처리를 안 적음 |
| 선택의 이유가 없다 | "X를 썼다"만 있고 왜 X인지 없음 |
| 수치의 산출 조건이 없다 | 어느 구간 자료로 만든 값인지 안 밝힘 |
| 예고한 지표의 값이 없다 | "평가한다"고 하고 결과에 안 나옴 |
| 순서가 뒤죽박죽 | 자료 → 모형 → 다시 자료 |

### ④ 결과

**수치와 주장의 크기가 맞는가.**

| 걸리는 신호 | 예 |
|--|--|
| 낮은 값에 높은 어휘 | 0.771을 "high accuracy"로 |
| 표·그림과 본문이 다르다 | 본문은 "유일하게 상승"인데 그림엔 둘이 상승 |
| 경계가 없다 | "이것만으로 말할 수 없는 것"을 안 적음 |
| 유리한 것만 보고 | 재현율을 빼고 정밀도만 |
| 비교 대상이 없다 | 기준선 없이 절대값만 |

### ⑤ 문법

| 볼 것 |
|--|
| 시제(선행연구·절차·결과·정의) |
| 능동과 수동, we의 자리 |
| 지시대명사가 무엇을 가리키는지 분명한가 |
| 비교 대상이 적혀 있는가 |
| 구두점, 쉼표 개수, 접속부사 자리 |
| 단수·복수, 관사 |

자세한 항목은 `05_영작규칙.md`, 국문은 `06_국문문체.md`.

### ⑥ 내용

**주장이 근거로 받쳐지는가.**

| 걸리는 신호 | 예 |
|--|--|
| 근거 없이 단정 | "리더가 없다"에 인용 없음 |
| 비약 | 표본에서 산업 전체로 |
| 인과 서술 | 관찰 자료인데 "때문에" |
| 중복 | 같은 발견을 결과·논의·결론에서 세 번 |
| 우리 자료가 못 말하는 것 | 특허로 채택을 말함 |

## §3. 독자 관점 (일곱째 측면)

**처음 읽는 사람이 걸리는가.** 이건 우리가 아는 것을 잊고 읽어야 보인다.

| 보는 것 | 물음 |
|--|--|
| **처음 읽는 사람** | 어디서 멈추는가. 두 번 읽어야 하는 문장이 어디인가 |
| **표만 보는 사람** | 본문을 안 읽고 표만 봐도 이해되는가 |
| **그림만 보는 사람** | 캡션과 그림만으로 무엇을 말하는지 아는가 |
| **초록만 보는 사람** | 초록만으로 무엇을 했고 무엇을 얻었는지 아는가 |
| **결론만 보는 사람** | 결론만으로 이 논문의 답이 무엇인지 아는가 |

심사자는 본문에서 몇 쪽 떨어진 표를 마주친다. **표와 그림은 홀로 읽혀야
한다.** 표·그림 안의 글자까지 검수하는 방법은 `09_그림과표.md` §8-2.

## §4. 몇 번 돌 것인가

두 가지 방식이 있다. **시작할 때 어느 쪽인지 정하고 기록한다.**

### 방식 A. 횟수를 정해 놓고 돈다 (기본 100회)

- 아래 각도 목록을 **순환**하며 정해진 횟수까지 돈다
- 회차마다 **각도·범위·새 지적 수**를 대장에 적는다
- **새 지적 수가 줄어드는 곡선**이 판단 근거다. 100회를 다 돌지 않아도
  연속 다섯 회차에서 0건이면 조기 종료할 수 있다
- 100회를 다 돌았는데도 계속 나오면 **문장 문제가 아니라 내용 문제**다.
  그 사실을 적고 위 층위로 올라간다

〔사례〕 실제로 105회를 돌렸다. 그런데 그중에 **원문을 여는 회차가 없어서**
인용 방향 오류를 못 잡았다. **횟수보다 각도의 다양성이 중요하다.**

### 방식 B. 횟수 제한 없이 각도를 바꿔 가며 돈다

- **새 지적이 연속 세 회차 0건**일 때까지 각도를 바꿔 가며 돈다
- 각도 목록을 다 돌았는데도 지적이 나오면 **목록을 늘린다**(아래 §5)
- 다만 안전장치는 그대로다. 같은 자리를 세 번 고치면 멈추고, 왕복이 생기면
  저자에게 묻는다(`15_직접대조_검수.md` §7-2)

**둘의 차이는 "언제 멈추나"뿐이다.** 읽는 방법은 같다.

### 회차 대장

```markdown
| 회차 | 각도 | 범위 | 새 지적 | 조치 | 누적 |
|--|--|--|--|--|--|
| 1 | 흐름 | 전체 | 12 | 수정 8, 유보 4 | 12 |
| 2 | 맥락 | 전체 | 7 | 수정 5, 기각 2 | 19 |
| 3 | 방법 | 3장 | 4 | 수정 4 | 23 |
| ... |
| 41 | 독자(표만) | 표 10개 | 0 | - | 118 |
| 42 | 독자(그림만) | 그림 6개 | 0 | - | 118 |
| 43 | 흐름(재독) | 전체 | 0 | - | 118 |
```

**"몇 회 돌았다"가 아니라 "어느 각도로 몇 회 돌았고 각각 몇 건 나왔다"로
보고한다.**

## §6. 수정 루프와 헷갈리지 않기

- **이 문서의 회차**는 "읽고 지적을 모으는" 캠페인이다. 100회든 무제한이든
  각도를 바꿔 가며 돈다
- **`15_직접대조_검수.md` §7-2의 상한**은 "한 자리를 고치고 다시 보는" 루프에
  건 제동이다. 같은 자리를 세 번 고치면 멈춘다

둘은 다르다. 각도를 바꿔 100회 읽는 것은 정상이고, 같은 문장을 100번 고치는
것은 무한루프다.

## §7. 보고 형식

```
각도별 읽기: 43회차까지 진행 (방식 B, 무제한)
- 각도 24종 중 24종 한 바퀴 완료, 2바퀴 진행 중
- 누적 지적 118건 (수정 89, 기각 21, 저자 결정 대기 8)
- 최근 세 회차 새 지적 0건 → 종료 조건 충족
- 나온 지적이 가장 많았던 각도: 흐름(21건), 내용(19건), 독자-표만(14건)
```

**각도별 건수를 함께 적는다.** 어느 각도에서 많이 나왔는지가 다음 논문에서
먼저 볼 자리를 알려 준다.
