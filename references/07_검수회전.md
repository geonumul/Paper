# 4-6단계. 검수: 기계 → 층위 → 각도

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차와 규칙은 분야·저널과 무관하게 쓰지만, 숫자와 사례는 **특허·건설 분야
> 논문 한 편(목표 저널 TFSC)에서 실제로 잰 값**입니다. 〔사례〕 표시가 붙은
> 것은 전부 그 논문 이야기입니다. **자기 저널에서 같은 방식으로 다시 재서
> 바꿔 넣으세요.** 무엇을 재는지가 이 문서의 내용이고, 얼마가 나오는지는
> 저널마다 다릅니다.


**집필을 먼저 완주한다.** 문단 하나 쓰고 검수하고 다시 쓰면 층위가 섞여 같은
종류의 결함을 놓친다. 검수는 탈고 뒤에 일괄로 한다.

## §1. 1겹 - 기계 검사

```bash
python scripts/check_style.py 원고.md      # 문체 8종
python scripts/check_ngram.py 원고.md      # 5-gram 겹침 + 문장 리듬
python scripts/manuscript_lint.py 원고.md  # 규격·참조·예고·문단·수치 정합
```

**원고를 고칠 때마다 돌린다. 통과 전에는 다음 겹으로 가지 않는다.**

| 검사 | 무엇 |
|--|--|
| ① 금지어·폐기 수치 | 저널 금지 표현 + 우리 옛 수치 |
| ② 이음말 밀도 | 실측 대역 밖이면 경고 |
| ③ 약어 미정의·초록 약어 수 | 초록에 둘 이상 금지 |
| ④ 소수점 자리 불일치 | 0.84와 0.842 혼재 |
| ⑤ 쉼표 4개 이상 문장 | 인용 괄호·짧은 괄호는 제외하고 셈 |
| ⑥ 번호 나열 연속성 | First→Fourth 건너뜀, Third 중복 |
| ⑦ 군말 반복 | "we believe", "likely" 류 |
| ⑧ 예고 시제 잔존 | "is evaluated"라 쓰고 값이 없는 것 |
| ⑨ 5-gram 겹침 | 인용 문헌 원문과 5단어 연쇄가 같은 자리 |
| ⑩ 문장 길이 변동계수 | 실측 대역(예: 0.52-0.79)과 대조 |
| ⑪ 규격 | 초록 낱말 수, 하이라이트 개수·글자 수, 키워드 개수 |
| ⑫ 부동체 참조 | 본문이 부르는 표·그림·부록이 실제로 있는가, 있는데 안 부르는가, 번호가 빠졌는가 |
| ⑬ 구성 예고 | "Section N에서 …"가 실제 절과 맞는가 |
| ⑭ 문단 길이 | 1-2문장짜리 문단 |
| ⑮ 수치 정합 | 초록에만 있는 값, 소수 자리 혼재 |

**검사기를 만들 때 반드시 넣을 다섯 가지**(안 넣으면 오탐이 쏟아져 못 쓴다).

1. 사람이 판정해 통과시킨 문장을 등재하는 **예외 목록 파일**
2. 기록 블록과 헤더는 스캔에서 제외, **본문만**
3. 쉼표 계수에서 **인용 괄호와 짧은 괄호(코드 나열) 제거 후** 계산
4. 이음말을 **소문자 포함**해 계측하고 목록을 확장
5. 국어 금지어 오탐 수정

그리고 **오류를 일부러 심은 시험 파일로 검사기를 자가 시험**한다. 검사기를
안 믿고 검사기를 검사하는 단계다.

자가 시험은 이렇게 한다.

1. 걸려야 하는 것과 **안 걸려야 하는 것**을 함께 심은 짧은 파일을 만든다
2. 검사기를 돌려 **의도한 것만 걸리는지** 본다
3. 고친 뒤에는 **숫자가 어떻게 바뀌었는지**로 확인한다("78 → 62 → 6")
4. 숫자가 안 바뀌면 고친 것이 안 먹은 것이다. 실제로 정규식에 보이지 않는
   제어문자가 들어가 그 검사가 **언제나 통과**한 적이 있다(`12` A15-2)

**5-gram이 걸리면**: 인용 처리는 **귀속 인용이거나 완전 재구성이거나 둘 중
하나만** 한다. 어중간한 근접 의역이 가장 나쁘다. 실제로 2건이 걸려 재구성했다
("is widely regarded as a", "over the past decade the").

## §2. 2겹 - 문단 카드

문단마다 같은 물음을 던진다.

| 물음 | |
|--|--|
| ① 첫 문장이 문단의 결론인가 | 두괄식 |
| ② 메시지가 하나뿐인가 | |
| ③ 수치가 있으면 비교·확인이 따라오는가 | |
| ④ 결과 문단이면 경계 문장으로 끝나는가 | "이것만으로 말할 수 없는 것" |
| ⑤ 앞 문단과 이음말 또는 논리로 이어지는가 | |
| ⑥ (서론이면) 이 문장을 연구 시작 전에 쓸 수 있었는가 | |

집필 중 병행할 때는 여기에 넷을 더해 **9층**으로 본다: 인용 귀속 정확 /
수치 정본 대조(산출 파일 번호) / 관찰 수위(금지선) / 문법·시제.

## §3. 3겹 - 절 카드

**서론**: 여섯 걸음이 있는가 / 갭이 "여기까지만" 형식인가 / RQ 번호가 있는가 /
기여 둘셋과 인용이 있는가 / 실명 사례가 있는가 / 성능 수치가 없는가 / 후렴이
있는가

**방법**: 자료·방법이 한 절인가 / 단계 번호+이름인가 / 선택마다 "왜"가 있는가 /
전처리 지면이 충분한가 / 예고한 지표가 결과에 다 나오는가 / 재현 안내가 있는가

**결과**: 첫 하위절이 검증인가 / 표에 판정 열이 있는가 / 코드에 설명이 붙었는가 /
발견과 해석이 짝인가 / 외부 대조가 있는가 / 경계 문장이 있는가

**논의**: 첫 문단이 결과 압축인가 / 목적 재진술로 시작하지 않았는가 / 관찰
수위를 지켰는가 / 후렴을 되받는가

**한계·결론**: 셋이고 번호가 맞는가 / 550단어인가 / 마지막이 자료 한계인가 /
결론이 RQ를 되받는가 / 위계가 있는가 / 정책 제언이 자료 안인가

**검수 순서**: 초안 → ①기계 → ②문단 카드 → ③절 카드 → ④수치 정본 대조 →
⑤영문화 후 기계 재검 → ⑥구성 예고 대조 → 제출본

## §4. 층위별 가로 훑기

**한 번에 한 층위만 들고 문서 처음부터 끝까지 간다.**
순서는 **낱말 → 문장 → 문단 → 소절 → 장 → 전체**.

> **이 절은 순서와 점검 항목만 다룬다.** 각 층위에서 게재작과 어떻게 직접
> 대조하는지, 무엇을 대장에 남기는지, 언제 그 층위를 닫는지는
> **`15_직접대조_검수.md`**에 있다. 실제 작업은 그 문서를 펴고 한다.

### 단어 층

**이 층은 전수다.** `word_census.py`로 원고의 낱말을 전부 뽑아 표로 만들고,
**모든 행에 판정을 적는다.** 표본으로 몇 개만 보는 것은 이 층을 안 한 것이다
(절차는 `15_직접대조_검수.md` §3).

1. **직접 읽으면서 멈춘 자리도 따로 적는다.** 개수를 정해 놓고 채우지 않는다
2. **그 표현이 게재작 코퍼스에 실제로 있는지 검색한다**
3. **고칠 말은 밖에서 가져오지 않고 원고 안에서 찾는다**

> 초록 첫 문장에 `patent construction automation`이라고 썼다가 읽다가 걸렸다.
> 특허를 내는 대상은 발명이지 분야가 아니기 때문이다. 코퍼스를 검색하니 우리가
> 쓴 꼴은 게재작에 없었다. 그런데 **이 논문이 이미 여섯 군데에서 같은 개념을
> 다른 낱말로 부르고 있었다.** 그 낱말로 통일했다. 밖에서 새 말을 가져올 필요가
> 없었다.

그다음 핵심 용어를 전체 문서에서 하나씩 추적한다. 이 층에서 `significant`가
통계 검정 없이 쓰인 자리를 찾아 `substantial`로 고쳤다.

### 문장 층

수치 검증은 다른 회차에서 하고, 여기서는 **문장 하나가 스스로 말이 되는지**만 본다.

- **인과어 전수 검색**: causes, caused, leads to, led to, results in, resulted
  in, drives, drove. 관찰 자료 논문에서는 0건이어야 한다
- **비교 대상 명시**: "higher than that of the baseline"에서 `that of` 생략 금지
- **강도 사다리가 근거 크기와 맞는가**
- **이중 완화 금지**
- **지시대명사 명시**

### 문단 층

§2의 다섯 물음 + **AI 티 전용 기계 스캔 둘**(`08_AI티제거.md`).
**두 스캔에서 걸린 것을 그대로 고치면 원고가 나빠진다. 반드시 수동 판정한다.**

### 소절 층

소절마다 **하려는 말 한 줄**과 **문단 배열 논리**를 표로 적는다.

| 소절 | 목적 한 줄 | 문단 배열 |
|--|--|--|
| 2.1 | 기존 전통과 그 사각지대 | 전통 → 특징1 → 특징2(침묵이 곧 우리 공백) |
| 4.2 | 무엇이 변했고 누가 이끌었나 | 추세 → 귀속 → 문헌 대비 → 분해 뉘앙스 → 실명 확인 |

**한 줄로 안 써지면 그 소절은 하려는 말이 둘이다.** 두 갈래를 다루려면 제목에
미리 예고하거나(제목에 "and"를 넣는다) 명시적 전환문을 둔다.

### 장 층

**이 층에서만 보이는 것이 있다.** 2장을 한 호흡에 읽고서야 소절 셋이 단순
나열이 아니라 **연쇄 연역**임을 알았다. 2.1의 결론을 2.2 첫 문장이 지시사로
받고, 2.2의 결론을 2.3 첫 문장이 다시 받는 구조였다.

점검은 셋이다. 장 서두의 예고와 실제 소절이 일치하는가 / 소절이 나열인가
연쇄인가 / 장 경계 전환이 매끄러운가.

장 경계는 **"앞 절 마지막 문단 ↔ 다음 절 첫 문단"을 직접 붙여 놓고** 본다.
예고-이행 패턴이 지켜지는지 확인한다.

### 전체 층

- **후렴 하나가 초록·서론·방법·결과·논의에 반복 등장하는가**
- **구성 예고와 실제 절 대조**(게재작 중에도 예고가 틀린 사례가 있다)
- **표·본문·초록 삼중 수치 정합**
- 번호 나열 연속성 재확인
- **익명성 유출 검사**
- 약어 최초 정의, 소수점 자릿수 일관성

## §5. 각도를 바꿔 재순회

층위 6단계를 1회차로 치고, 각도를 바꿔 아홉 회차를 더 돈다.

| 회차 | 각도 |
|--|--|
| 2 | **적대적 심사자 관점** ("어디를 공격할까") |
| 3 | 인용 정확성 감사 (원문 대조) |
| 4 | 결과 강도 어휘 사다리 |
| 5 | **AI 티 패턴 감사** |
| 6 | 표와 그림의 자립성 (본문 없이 캡션만으로 이해되는가) |
| 7 | 방법론 선례 인용 검증 |
| 8 | 소수점 자릿수 일관성 |
| 9 | 약어 최초 정의 |
| 10 | 전체 마무리 |

> **함정**: 적대적 심사자 회차에서 "가정 검정을 여섯 경우 전부 돌려야 하지
> 않나" 같은 지적이 나온다. 그런데 기준 삼는 게재작 둘 다 그걸 안 한다.
> **판단 기준을 "더 엄밀한가"가 아니라 "게재작 대비 적절한가"로 고정**하고
> 추가 작업 없이 종결했다.

지적이 나오면 순서대로 가른다. ①**desk reject 사유인가** ②아니면 게재작 기준으로
할 만한가 ③기준에 못 미치면 **하지 않는다.**

## §6. 의심 차원 12

"지적 하나에 규칙 하나"로 땜질하다 보면 규칙이 여러 문서에 흩어진다. 사후
지식을 가진 저자가 무의식적으로 저지르는 위반을 차원으로 묶는다.

| 차원 | 내용 | 검사 |
|--|--|--|
| A | 시점 자세: 서론 ①-⑤는 연구 전 지식만 | 문단 카드 ⑥ |
| B | **결정 대장 선행 조회**: 장 착수 전에 그 장의 결정을 전부 뽑아 본다 | 장별 대장 편찬 |
| C | 방법 선택의 사전 정당화: 결과를 보기 전에 댈 수 있던 이유인가 | 선택 문장 전수 목록화 |
| D | 질문·기대의 사후 조정 냄새 | RQ 문안 대조 |
| E | 설계된 척 금지: 나중에 붙인 관찰은 "추가 분석" 표지 | 절 도입부 점검 |
| F | 인용-주장 방향 정합: 원문이 실제로 그 주장을 하는가 | 전 회전 |
| G | 금지 서술 전수 대조 | 장별 대장 훑기 |
| H | 한계-주장 정합: 인정한 한계가 깎는 주장을 표로 대조 | 한계 × 주장 표 |
| I | 수치의 시점·범위 단서: 모든 수치에 산출 조건 | 수치 목록에 단서 열 |
| J | 표-본문-초록 삼중 수치 정합 | 기계 |
| K | 용어 정의 선행·일관: 정의 전 사용 금지 | 용어 첫 등장 위치표 |
| L | 두 언어 대역 정합: 한쪽만 고쳐 생기는 표류 | 문단쌍 대조 |

**운용 규칙**: 문단을 승인한 뒤에 B·F·G에서 위반이 발견되면 고치되, 반드시
**"승인 후 수정"으로 표시하고 재승인을 받는다.** 무단 확정을 하지 않는다.

## §7. findings를 관리하는 법

발견을 F1, F2로 번호를 붙여 관리한다. 각 항목에 **[분류, 상태, 조치]**를 단다.

```
## F9 [수치·방법론 오류, 확정, 수정함] - 5.2절 (567행)
## F8 - 되돌림 (사용자 지적으로 원문 복원. 기록은 참고용으로 남김)
## F12 해결 - [수치 근거 확인됨 + 서술 정확화, 수정함]
```

- **되돌린 것도 기록에 남긴다.** 왜 되돌렸는지가 다음 판단의 근거가 된다
- **사용자 결정이 필요한 것은 직접 고치지 않고** "확인/결정 필요"로 분리한다
- 회차마다 **누계**를 적는다("확정 findings 누계: F1-F14")

## §8. 고친 뒤에 하는 일

1. **그 수정 자체를 5회 의심한다.** 큰 수정은 10회
2. **수정으로 다른 곳이 상하지 않았는지 전체를 다시 본다**
3. **파생 파일까지 따라간다**: tex·PDF·서약 문서·그림·저장소 스크립트
4. **바꾼 낱말을 코퍼스와 다시 대조한다.** 고치다가 저널이 안 쓰는 말을 넣을
   수 있다

실제로 이 단계에서 잡힌 것들이다.

- 하이라이트에서 낱말을 고쳐 85자 상한을 넘겼다
- 초록에서 약어를 빼니 그 약어가 어디에서도 정의되지 않게 되었다
- 초록을 고치며 생긴 `those`에 선행사가 없어졌다
- 낱말을 바꾸다 한 문단에 `exceeds`가 두 번, 한 문장에 `tests test`가 생겼다
- 5.1절에 `Two limitations`를 넣으니 6.2절 "Four limitations"와 부딪혔다
- 주석에서 기간을 빼니 표(12쪽)와 본문(10쪽)이 두 쪽 떨어져, 표만 본 독자가
  어느 기간인지 알 수 없게 되었다

## §9. 검증 범위를 좁게 잡지 않는다

내가 바꾼 곳만 파면 원래 있던 결함을 못 잡는다. 열 회차를 돌고도 **그림 안의
글자**를 안 봐서 절 번호 오류와 사실과 다른 주장을 놓칠 뻔했다.

**"확인하고 안 건드렸다"는 판단에도 근거가 있어야 한다.** 재지 않았으면
재지 않았다고 말한다.
