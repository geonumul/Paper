# 번역 대조 (단독으로도 쓴다)

> **이 문서의 숫자를 그대로 쓰지 마세요.**
> 절차와 규칙은 분야·저널과 무관하게 쓰지만, 숫자와 사례는 특허·건설 분야
> 논문 한 편(목표 저널 TFSC)에서 실제로 잰 값입니다.

이미 쓴 원고를 번역해 둔 사람이 **두 판이 같은 말을 하는지만** 검사하러 올
수 있다(`/paper-to-journal 번역`). 다른 단계를 안 거쳐도 된다.

---

## 1항. 먼저 정할 것 하나

**어느 쪽이 정본인가.**

| 정본 | 뜻 | 검사 방향 |
|--|--|--|
| 국문이 정본 | 국문으로 쓰고 영문으로 옮겼다 | 영문이 국문을 다 담았는가 + 영문이 저널 톤인가 |
| 영문이 정본 | 영문으로 쓰고 국문 대역을 만들었다 | 국문이 영문을 다 담았는가 + 국문이 학술 문체인가 |

**정본이 아닌 쪽을 고쳐서 맞춘다.** 둘 다 고치기 시작하면 어느 쪽이 맞는지
알 수 없게 된다.

## 2항. 기계로 어긋난 자리를 먼저 뽑는다

```bash
python scripts/align_check.py 원고_영문.md 원고_국문.md
python scripts/unit_census.py 원고_영문.md          # 절별 문단·문장 수
python scripts/unit_census.py 원고_국문.md
```

`align_check.py`가 넷을 대조한다.

| 검사 | 어긋나면 |
|--|--|
| **단위 수**(절·문단·문장) | 문단이 갈라졌거나 합쳐진 자리가 있다 |
| **수치** | 옮기다 빠졌거나, 한쪽에서만 새로 계산했다 |
| **인용**(저자·연도) | 번역하며 빠뜨렸거나 더했다 |
| **약어** | 한쪽에만 정의가 있거나 표기가 다르다 |

〔사례〕 실제 출력이다.

```
| 단위 | 영문 | 국문 | 차이 |
| 절   |  30  |  31  | +1  **다름** |
| 문단 | 117  | 107  | -10 **다름** |

## ③ 인용
- 영문에만 있는 연도 2개(누락 후보): 2009(Zhang), 2011(Curran)
- 연도는 같은데 저자 표기가 다른 것 6개: 1986 Tushman↔Anderson, ...
```

**저자 표기 차이는 대개 문제가 아니다.** 국문은 "Gann과 Salter(2000)"처럼
둘째 저자를 쓰기도 한다. 도구가 그 둘을 갈라 보고한다.

**의미가 같은지는 기계가 못 본다.** 여기서 나오는 것은 자리 후보이고, 판정은
문단쌍을 나란히 놓고 읽어서 한다.

## 3항. 문단쌍을 전수로 대조한다

문단 번호를 붙여 짝을 짓고(`4.2-P3` ↔ `4.2-P3`), **모든 쌍에 판정을 적는다.**
"주요 문단만 봤다"는 이 층을 안 한 것이다.

쌍마다 다섯을 본다.

| 볼 것 | 어긋나는 예 |
|--|--|
| ① **같은 말을 하는가** | 한쪽에만 있는 문장, 한쪽에서 합쳐진 두 문장 |
| ② **수치가 같은가** | 자리 바뀜, 반올림 차이, 단위 누락 |
| ③ **수위가 같은가** | 국문 "시사한다"가 영문 "demonstrates"로 세짐 |
| ④ **조건이 살아 있는가** | "이 표본에서는", "굴착기를 빼면" 같은 한정어 누락 |
| ⑤ **용어가 일관되는가** | 한 국문 용어가 두 영문 용어로 갈림, 또는 그 반대 |

**③과 ④가 가장 자주, 가장 위험하게 어긋난다.** 번역하면서 문장이 매끄러워질
때 한정어가 빠지고 동사가 세진다. **다듬기가 주장을 키우면 그것은 다듬기가
아니다.**

### 용어 대응표를 만든다

| 국문 | 영문 | 일관되는가 |
|--|--|--|
| 기술군 | technology cluster | ○ (전체 동일) |
| 결합 | combination / convergence | **✗ 두 말로 갈림** |

한 낱말이 두 말로 갈리면 **하나로 고정한다.** 영문 쪽은 코퍼스 빈도와 맥락
다섯으로 고른다(`01_게재작수집_실측.md` 6항).

## 4항. 그다음은 각 판을 따로 본다

번역이 맞다고 끝이 아니다. 두 판은 각각의 기준으로 다시 봐야 한다.

- **영문**: 목표 저널 실측 기준으로 낱말·문장·문단 전수 대조
  (`15_직접대조_검수.md`). 번역투 문장이 저널 문형과 다른 자리를 찾는다
- **국문**: 국문 문체 정본 기준으로 본다(`06_국문문체.md`). 영문을 그대로
  옮긴 번역투("~에 의해 특징지어진다", "~하는 것이 가능하다")를 걷어낸다

```bash
python scripts/word_census.py 원고_영문.md --journal <저널>
python scripts/ko_measure.py 원고_국문.md --ref <국문 정본>
```

## 5항. 흔한 사고

| 사고 | 신호 |
|--|--|
| 수위가 세짐 | 영문에 demonstrates·proves·significant가 늘었다 |
| 조건절 누락 | 국문에 있던 "다만", "이 표본에서는"이 영문에 없다 |
| 한 낱말이 두 말로 | 용어 대응표에서 갈린다 |
| 문단 분할이 달라짐 | 문단 수 차이 |
| 표·그림 번호 어긋남 | `manuscript_lint.py`의 참조 검사로 각각 확인 |
| 초록만 새로 씀 | 초록의 수치가 본문과 다르다 |
